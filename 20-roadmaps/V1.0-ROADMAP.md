## Capability Ladder

The product evolved along a capability ladder rather than a subsystem roadmap:

```
vestara open
      ↓
vestara explain
      ↓
vestara plan
      ↓
vestara predict
      ↓
vestara recommend
      ↓
vestara implement
      ↓
vestara verify
      ↓
vestara collaborate
```

Each command produces a durable artifact. Each artifact becomes input to the next capability.

## Artifact Model

```
RepositoryWorkspace
  ├── RepositoryProfile     (understanding)
  ├── Explanations          (communication)
  ├── Plans                 (intent)
  ├── ImpactAssessments     (prediction)
  ├── Decisions             (recommendation)
  ├── ChangeSets            (execution)
  ├── VerificationReports   (evidence)
  └── CollaborationRecords  (coordination)
```

## Engineering Methodology

All capabilities follow **Vestara Specification-Driven Engineering (VSDE)**:

```
Product Principle → Specification → Architecture → Implementation → Verification → Metrics → Learning
```

See `docs/VSDE/` and `docs/PRODUCT-PRINCIPLES.md` in the implementation repository.

## Running the Platform

```bash
# Install and build
cd vestara-ai-core
pnpm install
bash build-order.sh

# Open any repository
pnpm vestara open .

# Full engineering lifecycle
vestara open .         → understand
vestara explain <target> → communicate
vestara plan <goal>    → plan
vestara predict <goal> → predict
vestara recommend      → decide
vestara implement <id> → execute
vestara verify <cs-id> → validate
```

47 tests verify the platform. All capabilities work offline with deterministic output. AI is optional enrichment.
