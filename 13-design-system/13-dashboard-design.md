# VDS Dashboard Design

Data visualization tokens, dashboard layout patterns, overview panel composition, card anatomy, progress indicators, and health/status widget design.

Routing dashboards SHOULD separate provider health dimensions from suitability
and recommendation. Assignment lists show task, revision, role/agent, provider
model, execution state, and side-effect state. Terminal dashboards use compact
tables only when columns fit; otherwise use stacked records.
